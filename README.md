### Опыт

**МегаФон · ML-инженер**  
LLM-поддержка: субагенты по SOP, гибридный RAG, QLoRA для длинных диалогов, оценка перед релизом.  
Покрытие выросло с **5% до 34%** при ~28 тыс. обращений в сутки. Среди взятых в работу доля без оператора выросла с **44,3% до 87,5%**. Recall@10 фрагментов в контексте модели: **0,78 → 0,94**.

**ЦФТ · ML-инженер**
